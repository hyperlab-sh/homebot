You’ll forget. Your homebot will not.

Built for ADHD brains. Works for every busy one.

But seriously, who is this for?

homebot is a dotfiles manager for people who won’t remember to run it.

It keeps your dotfiles, secrets and install lists in one git repo, does the chores on its own, and tells you what still needs you.

Pick the robot that inspires you the most

Your homebot talks in its robot’s voice.
A voice changes the sentences and nothing else:
the items, paths, commands and counts stay the same.

It comes to you

You don’t have to remember to check. When something needs you, a new shell says so in one line. Type homebot and you get one short list, most urgent first, and every item ends with the command that fixes it.

The hourly helper does the rest: it seals secrets, commits, pushes and repairs links while you work, and tells you what it did.

homebot works too. The name is a second way to call it.

What it takes off your mind

Each of these started as something that kept slipping.
homebot handles the remembering, so you only handle the decisions.

  • It comes to you

    Out of sight, out of mind.

    A line when a shell opens, a count in your prompt, and a desktop notification when something urgent appears. The shell line and the prompt count are zsh only for now.

  • Start without planning

    “Where do I even start?”

    At most five items, most urgent first, each ending with the command that fixes it. homebot next runs the first one.

  • Chores happen anyway

    The things that only happen when you remember them.

    Every hour a background helper seals secrets, refreshes package lists, commits, pushes and repairs links. A step that fails becomes an item in your list.

  • Decide once

    The same question, every week.

    New files in your home folder get asked about once: track, ignore or snooze, one key each. The answer lives in your repo, so every machine knows it.

  • Safe when you’re distracted

    Half a command, then a meeting.

    It never overwrites a file. --dry-run shows the steps first. Ctrl-C leaves nothing half done, and the commit guard refuses to commit a leaked secret.

  • Pick up where you left off

    Coming back after three weeks away.

    “Done for you since you last looked” lists what the helper did while you were gone, and the list still shows only what needs you now.

What the helper never does

It runs while you aren’t watching,
so it only does what is safe to do unwatched.

  • It never overwrites a real file.
  • It never commits a file git doesn’t already track, except sealed secrets and package lists. New files wait for you.
  • It never decrypts anything. That needs your passphrase.
  • It never resolves a conflict for you.

And the dotfiles part,
done properly

Your home repo is one folder in git, ~/.home.
The folder a file is in is its configuration.

  • Links

    Everything in autolink/ is linked into $HOME, so editing the repo edits the live file. When a real file is in the way, homebot stops and says so. Nothing is deleted.

    The linking rules

  • Secrets

    Files in private/ are linked like the rest, but git only ever sees them encrypted with age. Sealing needs no passphrase, so it happens before every commit.

    How secrets work

  • Profiles

    A profile lists what a machine gets, in order: brew, apt and flatpak lists, fonts, your own scripts. A laptop and a server share a base and differ in the rest.

    Profiles and packages

Behind homebot

Saulo Vallory

Senior software engineer and architect. Maker of homebot.

Did you know a lot of us with ADHD love having things organized?
And that it helps A LOT to keep us on track when they are?
Aaaand that keeping them that way is very hard for us?
haha, what a cosmic joke, right?

For years I dreamt of a tidy, well-organized home dir and dotfiles.
And I got there! 3 times. For about a month each time.

So this time, instead of doing a whole-home remodel (again), I built a system that does that for me but, most importantly, that keeps itself organized.
Or at least puts whatever it needs from me right in front of my face.

That’s homebot.
